# Poligon Hat 04

Tarayıcıda çalışan 3D kapalı atış poligonu oyunu (Three.js).

**Oyna:** https://www.yigiterenkaptan.com/

Modlar: Hassas Atış (ondalık skor, grup çapı), Refleks (çelik plakalar, tepki süresi), Hareketli Hedef (seri çarpanı). Masaüstünde fare ve klavye, mobilde dokunmatik kontrollerle oynanır.
